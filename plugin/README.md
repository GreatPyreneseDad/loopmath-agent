# loopmath Claude Code plugin

```
/plugin marketplace add GreatPyreneseDad/loopmath-agent
/plugin install loopmath
/loopmath
```

Installs the `loopmath` MCP server (`npx -y loopmath-agent mcp`), a skill
that triggers on cost / runaway-loop / cache-miss questions, and a
`/loopmath` command. See https://gitdr.ai/agent.md.
